塔羅妹 TarotMui — 私隱政策

最後更新：2026年8月9日 · 適用於 iOS App「塔羅妹 TarotMui」（Bundle ID：com.tarotmui.TarotMui）及「塔羅妹 占卜師版」（Bundle ID：com.tarotmui.TarotMuiReader）

我們重視你的私隱。本政策說明我們如何收集、使用、儲存及保護你的個人資料。

1. 我們收集的資料

  • 帳戶資料：Apple ID、Google 帳戶、匿名訪客識別碼；顯示名稱、用戶名、頭像、出生日期、性別（如你自願提供）。占卜師申請或轉帳設定中，你亦可自願提供聯絡電話。
  • 占卜與使用記錄：塔羅／占星／每日一牌記錄、真人諮詢與直播互動、即問即答與文章參與記錄。
  • 推播相關：Apple 推播裝置 token（APNs），用於每日提醒、文章答案公布等通知；你可於系統設定關閉通知。
  • 麥克風：僅在你使用語音直播或一對一語音諮詢時，經你授權後使用；我們不會在背景偷偷錄音。
  • 相機：僅在你拍攝占卜師申請／KYC 證件相片時，經你授權後使用。
  • 相片：僅在你上傳頭像、文章圖片或提交占卜師 KYC 證件時，經你從相簿選擇後上傳。
  • 購買記錄：透過 App Store 購買「占卜幣」的交易記錄（由 Apple 處理付款，我們不儲存信用卡資料）。
  • 內容舉報：你提交的舉報／封鎖相關資訊，用於社群安全與審核。
  • 技術資料：App 版本、裝置類型、錯誤日誌（用於改善穩定性）。

2. 資料用途

  • 提供登入、同步雲端帳戶及占卜幣／收益錢包
  • 提供塔羅占卜、真人諮詢、直播、文章及推播服務
  • 處理 App 內購買與占卜幣消耗
  • 防止濫用、處理舉報、保障平台及用戶安全
  • 改善產品體驗及客戶支援
  • 處理帳戶刪除申請

3. 第三方服務

我們使用以下服務處理資料，各服務均有其私隱政策：

  • Supabase — 帳戶、資料庫、雲端儲存，以及我們託管的 Edge Functions（伺服器端代理）
  • FreeAstroAPI — 占星本命盤計算；你提交的出生日期／時間／地點等資料，會經我們的 Supabase Edge Function 轉傳至 FreeAstro（App 不會直接持有其 API 金鑰）
  • AI 模型供應商 — 我們會按服務配置使用 DeepSeek、OpenRouter、Groq、OpenAI 或 Gemini 等供應商生成 AI 解讀；完成服務所需的精簡資料會經我們的 Supabase Edge Function 轉傳至目前配置的供應商
  • Apple — Sign in with Apple、App Store 付款、APNs 推播
  • Google — Google 登入（如你選擇）
  • Agora — 語音直播（如你使用語音功能）

占星計算與 AI 解讀的典型路徑為：你的裝置 → 我們的 Supabase Edge Function → FreeAstro 或目前配置的 AI 模型供應商（HTTPS）。我們會盡量只傳送完成服務所需的最少資料（例如精簡星盤落點），不會為生成解讀而主動傳送不必要的帳戶資料。第三方如何處理及保留資料，受其各自的私隱政策及我們所用服務方案約束；請勿在輸入欄填寫身分證號碼、電話或詳細住址等敏感個人資料。

4. 本機私隱選項

  • 解讀同步雲端：你可於 App「設定 → 私隱與資料」關閉占卜／解讀記錄上雲；關閉後，相關記錄主要保留於本機裝置。
  • 本機敏感欄位加密：你可選擇以裝置金鑰加密本機儲存的問題與解讀文字（金鑰存於系統 Keychain）。若你開啟雲端同步，上雲前會以明文傳送至我們的伺服器以便跨裝置還原。

5. 資料保留與刪除

我們會在提供服務所需期間保留資料。你可於 App「設定 → 帳號與安全 → 刪除帳戶」申請刪除，或聯絡 tarotmui74@gmail.com 要求刪除個人資料。成功送出申請後，我們會在30 日內完成帳號及相關個人資料刪除（法律要求保留的記錄除外，例如財務／爭議相關資料）。若伺服器申請未能即時寫入，請電郵確認，我們仍會於收到確認後 30 日內處理。

6. 兒童私隱

本 App 面向 17 歲或以上用戶。我們不會故意收集 17 歲以下兒童的個人資料。

7. 你的權利

你可要求查閱、更正或刪除個人資料，或撤回推播／麥克風／相機等系統權限（可能影響部分功能）。
